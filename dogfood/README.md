# Dogfood Fixtures

This folder contains committed synthetic inputs for repeatable local dogfood runs.

Use committed fixtures for authored, anonymous, license-clean test material. Keep generated run outputs, downloaded article text, scraped pages, private notes, and benchmark results under `.run/`.

Current fixture sets:

- `extract_lite/`: small extract-mode inputs covering evidence, entities, work items, and a chunked research case.
- `summary_lite/`: synthetic summarize-mode inputs covering brief notes, meeting notes, incident analysis, and a chunked strategy memo.
